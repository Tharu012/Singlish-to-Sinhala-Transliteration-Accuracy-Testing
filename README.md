# Singlish to Sinhala Transliteration Accuracy Testing

## Project Description
The purpose of this project is to test the accuracy of the Chat Sinhala transliteration function available at Pixelssuite Chat Translator.

The main objective is to identify cases where the application incorrectly converts informal chat-style Singlish input into Sinhala output. The project uses automated test cases to compare the expected Sinhala output with the actual output generated by the application.

## Application Under Test

Website: https://www.pixelssuite.com/chat-translator

Feature tested: Chat Sinhala transliteration

## Scope of Testing

This project focuses only on testing the correctness of the Chat Sinhala transliteration function.

The following areas are not tested:
- Standard Sinhala transliteration
- Backend APIs
- Performance testing
- Scalability testing
- Security testing

## Test Case Description

The test cases are prepared as negative test scenarios. Each test case checks whether the system fails to correctly convert chat-style Singlish input into Sinhala output.

The test cases cover different Singlish input types such as:
- Question forms
- Command forms
- Greetings
- Requests
- Responses
- Repeated words
- Inputs with punctuation marks
- Romanization and spelling variants
- English word insertions
- Multi-word English phrases
- English digital terms
- Platform or app names
- English abbreviations and acronyms
- English clipped forms
- Place names
- Person names
- Numbers and numeric suffixes
- Currency
- Time formats
- Dates
- Units of measurement
- Slang and casual phrasing
- Online identifiers
- Emojis
